## 部署步骤

1. 将 `Release\WeComNotify.dll` 复制到飞秋安装目录的 `Plugins\` 文件夹
   - 飞秋安装目录一般在：`C:\Program Files (x86)\飞秋2013\` 或飞秋所在目录
2. **修改 Webhook URL**（二选一）：
   - **方法 A（推荐）**：用文本编辑器打开 `WeComNotifyModule.cpp`，找到：
     ```cpp
     m_strWebhookUrl = _T("");
     ```
     替换为你的企业微信 Webhook URL，然后重新编译
   - **方法 B**：编译后通过飞秋界面配置（需在插件代码中补充配置对话框）
3. 重启飞秋，右下角托盘右键 → 应出现「转发到企业微信」菜单项

## 获取企业微信 Webhook URL

1. 打开企业微信 PC 端
2. 进入欲接收消息的群聊
3. 右上角「...」→ 群机器人 → 添加机器人
4. 创建后复制 Webhook 地址，格式：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx
   ```

## 常见问题

### 编译错误：找不到 `afxwin.h`
→ 安装 VS 时未勾选「C++ MFC」，重新运行 Visual Studio Installer 修改安装。

### 编译错误：找不到 `FeiQ.tlb`
→ 确认 `..\include` 和 `..\tlb` 目录存在，且 `FeiQ.tlb` 在 `tlb\` 下。
   若目录结构不同，修改 `WeComNotify.vcxproj` 中的 `<IncludePath>`。

### 插件加载失败（飞秋启动后无菜单）
→ 检查 DLL 是 Win32（x86）不是 x64。飞秋 2013 是 32 位程序，必须编译 Win32 版本。
→ 用 `dumpbin /dependents WeComNotify.dll` 检查是否缺少 MFC 运行库。

### 消息未转发到企业微信
→ 确认 Webhook URL 已正确设置（在 `WeComNotifyModule.cpp` 中）
→ 确认飞秋托盘菜单中「转发到企业微信」已勾选（有 √）
→ 检查本机能否访问 `qyapi.weixin.qq.com`（浏览器打开测试）
