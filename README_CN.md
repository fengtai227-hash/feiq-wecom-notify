## 功能特性

- ✅ 飞秋文字消息实时转发到企业微信群机器人（支持中文、英文、数字）
- ✅ 截图/图片自动识别，推送摘要通知（企业微信 webhook 不支持图片消息，改为文字提醒："有人发了一张截图，请到飞秋查看"）
- ✅ 托盘菜单一键开关转发功能（重启飞秋后保持开关状态）
- ✅ 配置对话框：自定义 Webhook URL + @提醒用户ID
- ✅ 多级二进制内容检测管线，精确区分文字与截图/文件数据
- ✅ 长消息自动截断（>550字符），适配企业微信 2048 字节限制

## 快速开始

### 第一步：获取企业微信 Webhook 地址

1. 打开企业微信，进入目标群聊
2. 群设置 → 群机器人 → 添加机器人 → 复制 Webhook 地址
3. Webhook 地址格式：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx`

### 第二步：安装插件

1. 从 [Release 页面](https://github.com/fengtai227-hash/feiq-wecom-notify/releases) 下载最新版 `WeComNotify.dll`
2. 将 DLL 复制到飞秋工作目录下的 `Plugins\` 文件夹中
3. 重启飞秋

### 第三步：配置插件

1. 右键点击飞秋系统托盘图标
2. 选择 **"配置企业微信..."**
3. 粘贴 Webhook 地址到输入框中
4. （可选）在 "@用户ID" 栏填入企业微信用户ID，多个用逗号分隔（如 `zhangsan,lisi`）
5. 点击确定保存

### 第四步：开启转发

1. 右键点击飞秋系统托盘图标
2. 点击 **"转发到企业微信"**，勾选状态即为已开启
3. 现在其他飞秋用户发给你的消息就会自动转发到企业微信群了

## 使用方法

### 正常操作流程

| 步骤 | 操作 |
|------|------|
| 1 | 确保飞秋正在运行，且插件已加载（托盘菜单中出现"转发到企业微信"选项） |
| 2 | 右键飞秋托盘图标 → **配置企业微信...** → 填入 Webhook 地址和 @用户ID |
| 3 | 右键飞秋托盘图标 → 勾选 **转发到企业微信** |
| 4 | 文字消息 → 直接转发到企业微信；截图/图片 → 推送摘要通知 |
| 5 | 不需要时取消勾选即可关闭转发 |

### @提醒用户

在配置对话框的 "@用户ID" 一栏填入企业微信用户ID，多个用逗号分隔：

```
zhangsan,lisi,wangwu
```

每条转发的消息都会 @这些用户，确保他们能及时看到。

### 开关状态持久化

转发开关状态会保存在飞秋的用户配置中，重启飞秋后无需重新设置。

## 从源码编译

### 环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| Visual Studio Build Tools | 2022 (v143) | 或 VS2022 完整版 |
| Windows SDK | 10.0 | 随 VS2022 安装 |
| 飞秋 SDK | 2013 | 包含在飞秋安装目录中 |

### 编译步骤

```bash
# 使用 VS2022 Developer Command Prompt 或 MSBuild 命令行
msbuild src/WeComNotify.vcxproj /t:Rebuild /p:Configuration=Release /p:Platform=Win32

# 或使用批处理脚本
cd src
build-release.bat
```

编译产出：`Release/WeComNotify.dll`

> 详细编译说明请参阅 [docs/BUILD.md](docs/BUILD.md)

### 注意事项

- 必须使用 **Win32 (x86)** 平台，64 位编译不兼容飞秋
- 代码基于 **MBCS** 字符集，编译选项需包含 `/utf-8`
- 如果同时安装了多个 VS 版本，确保 MSBuild 使用 v143 toolchain
- 如需生成 VC++6.0 格式项目，请参考 `WeComNotify.dsp` 文件

## 二进制检测原理

飞秋的截图/图片消息在 `BeforeRecvMsg` 回调中并非标准 JPEG/PNG 二进制数据，而是飞秋自有协议编码。插件采用 5 级检测管线来区分文字和图片：

| 层级 | 检测方法 | 说明 |
|------|----------|------|
| P0 | 飞秋协议帧 | 首字符为 `~` 或 `/~`、`/-`、`/#` 即判定为非文字数据 |
| P1 | 标准图片头 | 匹配 JPEG (`FF D8`)、PNG (`89 50 4E 47`)、GIF、BMP、RIFF |
| P2 | 长度阈值 | 超过 10KB 的消息几乎一定是图片/文件 |
| P3 | 文本可读性 | 前 64 字节中无任何字母、汉字或空格 → 判定为编码数据 |
| P4 | 非打印字符比 | GBK 双字节感知的非打印字符统计，>30% 判定为二进制 |

任意一级命中即停止检测，优先使用最可靠的检测方法。

## 企业微信限制说明

| 限制项 | 说明 |
|--------|------|
| 消息内容 | 仅支持文本消息，**不支持直接发送图片** |
| 消息长度 | 单条消息最大 **2048 字节**（中文约 680 字，英文约 2048 字符） |
| 发送频率 | 每个机器人每分钟最多 **20 条消息** |
| 图片消息 | 插件检测到截图时会推送文字摘要，提示用户在飞秋中查看原图 |
| 文件传输 | 飞秋的文件传输事件不走 `BeforeRecvMsg` 回调，当前版本暂不支持文件传输通知 |

## 技术架构

| 组件 | 技术 |
|------|------|
| 插件框架 | VC++6.0 MFC Extension DLL |
| 编译器 | VS2022 Build Tools (v143 toolchain) |
| 字符集 | MBCS (GBK) + `/utf-8` |
| HTTP 通信 | WinHTTP |
| 消息编码 | GBK → UTF-16 → UTF-8（适配企业微信 API） |
| 二进制检测 | 5 级管线（协议帧 + 文件头 + 可读性 + 长度 + 非打印字符比） |
